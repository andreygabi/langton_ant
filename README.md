Описание

Этот проект представляет собой реализацию клеточного автомата "Муравей Ленгтона" на Python. Муравей Ленгтона двигается по двумерной сетке клеток, изменяя цвета клеток и создавая при этом узоры, которые могут варьироваться от простых повторяющихся структур до сложных фрактальных узоров.

Примеры правил, которые можно использовать для получения различных узоров

1. RLR: Хаотичный рост
2. LLRR: Симметричный рост
3. LRRRRRLLR: Заполняет пространство в квадрате вокруг себя
4. LLRRRLRLRLLR: Создаёт извилистую магистраль
5. RRLLLRLLLRRR: Красивый паттерн

Минимальные требования для запуска проекта:
1. Python3
2. Pygame 2.5
